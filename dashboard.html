⚠️ Services Not Running

Connection Refused Error: This is normal! The backend services aren't started yet.

To Start Services:

  1. Install Docker Desktop (if not installed)
    Download: https://www.docker.com/products/docker-desktop/
  2. Start Docker Desktop and wait for it to be running
  3. Start services:
    docker compose up -d
    Or run: scripts\start.bat
  4. Wait 10-15 seconds for services to start
  5. Click "Refresh Status" button above
